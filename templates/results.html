Installation Instructions

{{ out_name }} is a wrapper that contains two separate mod ZIPs. You must install both as separate mods — the game needs each one active at the same time.

  1. Unzip {{ out_name }} — you'll find two files inside:
    • {{ out_name | replace('.zip', '') }}-data.zip — modified game data (DAT, tech trees)
    • {{ out_name | replace('.zip', '') }}-ui.zip — civ names, icons, AI stubs
  2. Unzip both of these to your local mods folder - usually located in C:\Users\yourname\Games\Age of Empires 2 DE\12345678\mods\local, where '12345678' is the folder for profile. You may have to test.
    Pro Tip: Create a shortcut for this folder and pin it to your File Explorer sidebar
  3. In the game's Mods → Installed list, make sure both mods show a green checkmark (active). Turn off any other mod that changes game data, such as another civ or balance mod: a game uses only one data mod.
  4. For every game, set Data Mod to {{ mod_name }} in the game setup screen. In multiplayer the host picks it.
If something looks wrong:
Your civ shows its bonuses in the selection screen, but the game plays the original civ (its buildings, voices, tech tree and unique unit)? The data mod isn't in use: check step 4, and that no other data mod is active.
Your civ plays correctly but shows the old name and icons? The UI mod isn't active (step 3), or another UI mod has a higher priority.

Extend Your Mod

Have an idea Empire Forge doesn't cover, such as villagers that build rams or Outposts that explode when destroyed? You can add your own changes on top of this mod with a small Python script that edits its data file. Rebuilding your civ never loses them: run the script again.
