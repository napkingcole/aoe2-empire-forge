How It Works

A quick guide to building and installing your first custom civilization mod.

What is AOE2: Empire Forge?

AOE2: Empire Forge is a standalone civ builder for Age of Empires II: Definitive Edition. Design a civilization from scratch — name, architecture, tech tree, unique unit, bonuses, and unique techs — then generate a fully playable mod, right from your browser. No Python knowledge, no manual file editing, no third-party tools required.

Empire Forge reads your game's data file (empires2_x2_p1.dat) directly and patches your custom civ into it, so it stays up to date with whatever version of AoE2:DE you have installed.

What You Need
  • Age of Empires II: Definitive Edition installed on your machine (Steam or Microsoft Store). Empire Forge will find your game data automatically.
  • That's it. No extra tools, no modding experience, no manual file editing.
Two Ways to Get Started
A
Build a New Civ from Scratch Recommended

Click Build Civ in the nav and step through the wizard. You'll name your civ, pick an architecture set, configure the tech tree, design a unique unit, select bonuses, and set up unique technologies. Each step is self-contained and saves automatically. When you're done, take the generated .civbuilder.json to Build Mod to generate the game file.

B
Convert a KrakenMeister Civ

Have an existing civ from KrakenMeister's builder? Use Convert KM Civ on the Build Civ page to import it into Empire Forge format, then edit and extend it in the wizard before building your mod.

Building the Mod

Once you have one or more .civbuilder.json files from the wizard, go to Build Mod:

  1. Upload — drop your .civbuilder.json files onto the upload page. Empire Forge will auto-detect the path to your game's DAT file.
  2. Configure — drag civs into the order you want, and choose which vanilla civ slot each one replaces. Any vanilla civ can be a target — the original is overwritten in the mod only; your game files are never touched.
  3. Build & Download — click Build Mod. Processing takes a few seconds, then you get a .zip ready to install.
Installing the Mod (Locally)

The download contains two mod ZIPs — both must be installed and active at the same time.

  1. Unzip the download — inside you'll find:
    • yourmodname-data.zip — modified game data (DAT file, tech trees)
    • yourmodname-ui.zip — civ names, icons, AI stubs
  2. Unzip both into your local mods folder: C:\Users\yourname\Games\Age of Empires 2 DE\[profileid]\mods\local\
    Each mod should land in its own subfolder inside local\.
  3. In the AoE2:DE in-game mod manager, make sure your UI mod is enabled. When creating a game (skirmish), select Your Mod Name as the data mod. The UI mod is automatically enabled.
If only the data mod is active, your civs will play correctly but show their original vanilla names and icons on the civ selection screen. Both mods must be active together.
Limitations

Most bonuses and tech tree configurations are fully supported. A small number of exotic bonus effects aren't implemented yet. See the Known Limitations page for the full list.

Unsupported bonuses are silently skipped — the rest of the civ builds normally. The Results page will show exactly what was applied and what was skipped.
